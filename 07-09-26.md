# Com funciona la ràdio al mòbil sense receptor FM?

## 1. Concepte principal
L'aplicació **no capta ones de ràdio reals (FM)**, sinó que reprodueix l'emissió a través d'Internet (**streaming**) utilitzant la teva connexió Wi-Fi o de dades mòbils.

---

## 2. Rutes de connexió a la xarxa

### Opció A: Connexió via Wi-Fi (a casa o oficines)
* **Tram 1 (Sense fils / *Wireless*):** El mòbil es connecta al router Wi-Fi mitjançant radiofreqüència local.
* **Tram 2 (Cablejat / *Wired*):** El router Wi-Fi està connectat per cable (Ethernet / fibra òptica) al router d'accés de l'ISP (proveïdor d'Internet).
* **Tram 3 (Internet Global):** El senyal viatja per la xarxa global fins arribar al servidor d'*streaming* de l'emissora.

```text
[ Mòbil ]
   │
   │ (Sense fils / Wi-Fi)
   ▼
[ Router Wi-Fi ]
   │
   │ (Cablejat / Ethernet - Fibra)
   ▼
[ Router d'accés / ISP ]
   │
   ▼
[ Internet Global (Servidor d'àudio de l'emissora) ]
```

---

### Opció B: Connexió via Dades Mòbils (4G / 5G al carrer)
* **Tram 1 (Sense fils / *Wireless*):** El mòbil es connecta a l'antena o estació base (*Base Station* / eNodeB / gNodeB) mitjançant la xarxa cel·lular.
* **Tram 2 (Cablejat / *Wired*):** L'estació base està connectada per una xarxa cablejada (*backhaul* de fibra òptica) als routers centrals de la companyia telefònica (*Core Network*).
* **Tram 3 (Internet Global):** La xarxa de l'operadora dóna sortida cap a Internet fins al servidor de l'emissora.

```text
[ Mòbil ]
   │
   │ (Sense fils / 4G-5G)
   ▼
[ Estació Base (Torre de telefonia) ]
   │
   │ (Cablejat / Fibra òptica de retorn)
   ▼
[ Routers centrals de l'operadora ]
   │
   ▼
[ Internet Global (Servidor d'àudio de l'emissora) ]
```

---

## 3. Conclusió
El contingut d'àudio es transmet exclusivament en format de paquets de dades digitals (IP) a través d'infraestructura d'Internet cablejada durant la major part del trajecte, utilitzant només connexió sense fils en el tram final entre el dispositiu (mòbil) i el punt d'accés (router o antena).
